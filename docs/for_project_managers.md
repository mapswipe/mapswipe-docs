# For MapSwipe Managers

Reference for MapSwipe project managers — how to obtain manager access, how to create projects and tutorials, and how the manager dashboard's directory pages (Organisations, Managers, Contributors, User Groups, Teams) are structured.

- [Managers](/docs/for_project_managers/managers/) — the manager directory, plus how to become a manager, sign in, and revoke access.
- [Projects](/docs/for_project_managers/projects/) — creating, processing, and publishing MapSwipe projects.
- [Tutorials](/docs/for_project_managers/tutorials/) — creating and managing project tutorials.
- [User Groups](/docs/for_project_managers/user_groups/) — community-managed groups contributors can join.
- [Contributors](/docs/for_project_managers/contributors/) — MapSwipe app users who contribute results.
- [Organisations](/docs/for_project_managers/organisations/) — the requesting organisations behind each project.
- [Teams](/docs/for_project_managers/teams/) — private teams managed by the super admin.
